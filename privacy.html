Privacy Policy for AI Companion for Claude

Last updated: June 11, 2026

AI Companion for Claude is a Chrome extension that runs on https://claude.ai/*. It adds usage indicators, local chat organization tools, a todo list, saved prompts, thinking-block expansion, and an optional Prompt Enhancer for prompts you choose to rewrite.

This policy explains what data the extension handles, how that data is used, where it is stored, and when it is shared.

Single Purpose

The extension's single purpose is to improve the signed-in claude.ai user interface with local productivity tools and optional prompt rewriting. The extension uses data only for the user-facing features described in this policy.

Data the Extension Handles

The extension handles data only on claude.ai and through the extension options page.

Depending on which features are enabled, the extension may access or process:

  • Claude page content and page structure needed to insert extension controls, organize the sidebar, hide or show Claude's native Recents section, and expand visible thinking blocks.
  • Claude authenticated API responses requested from claude.ai, including usage limits, usage percentages, reset times, prepaid credit balance, organization identifiers, membership or account metadata needed to identify the active organization, project metadata, and chat metadata.
  • Chat and project metadata used by the local organizer, such as project IDs, project titles, chat IDs, chat titles, chat order, starred state, custom section names, collapsed state, pinned chats, and panel visibility.
  • Extension settings, including enabled features, visible usage bars, colors, thresholds, and light or dark widget choices.
  • Todo text and todo completion state that you create in the extension.
  • Saved prompt text that you choose to save in the extension.
  • The current prompt text only when you click Enhance Prompt or Save Prompt.
  • Your IP address and request metadata when you use Prompt Enhancer, as processed by Cloudflare for request handling and rate limiting.

The extension does not intentionally collect or store full Claude conversation transcripts, Claude cookies, Claude authentication tokens, passwords, browser history, analytics identifiers, or browsing activity outside claude.ai.

How Data Is Used

The extension uses the data above only to provide and improve its user-facing features:

  • Usage and credit data is used to display the floating usage widget.
  • Claude organization identifiers are used to request the relevant Claude usage, project, and chat data for your signed-in session.
  • Claude project and chat metadata is used to render and update the local sidebar organizer.
  • Page content and page structure are used to place extension controls, expand visible thinking blocks when enabled, and keep the extension UI aligned with Claude's interface.
  • Settings are used to remember feature toggles, visible bars, colors, thresholds, and theme choices.
  • Todo text is used to display your local todo list.
  • Saved prompt text is used to show and reinsert prompts you choose to save.
  • Prompt text sent through Prompt Enhancer is used to generate a rewritten prompt.
  • IP-based rate-limit data is used to prevent abuse of the Prompt Enhancer service.

The extension does not use user data for advertising, personalized advertising, retargeting, sale, data brokerage, credit decisions, or unrelated analytics.

Storage

The extension uses Chrome extension storage for normal extension operation.

Chrome sync storage is used for extension settings, including feature toggles, widget preferences, visible bars, colors, thresholds, and theme choices. If Chrome Sync is enabled in your browser, Chrome may sync this settings data through your Chrome or Google account. The extension developer does not receive this settings data from Chrome storage.

Chrome local storage is used for local feature data, including:

  • Todo items and todo collapsed state.
  • Saved prompts that you choose to save.
  • Sidebar organizer state, including custom header names, header order, collapsed state, chat IDs assigned to headers, remembered chat titles, pinned chats, top-level chat IDs, project ordering choices, and panel visibility.

If Chrome extension storage is unavailable, the todo list and todo collapsed state may be stored in the browser's local storage for claude.ai as a fallback.

Usage responses, prepaid credit responses, project API responses, and chat API responses are kept only in memory while the extension is running and are not intentionally persisted by the extension.

Network Requests and Sharing

The extension makes same-site requests to claude.ai authenticated endpoints to display usage data and support organizer actions. These requests are sent to Claude/Anthropic as part of your existing signed-in Claude session. The browser may include your Claude cookies with those requests, but the extension does not read, copy, or store the cookie values.

If you click Enhance Prompt, the extension sends the current prompt text to:

  • https://claude-prompt-enhancer.batchbuddy.workers.dev, a Cloudflare Worker operated for this extension.
  • Anthropic's Messages API, which the Worker calls to generate the rewritten prompt.

Prompt Enhancer sends only the prompt text needed for that action. It does not send your full chat history, saved prompts list, todos, Claude usage data, Chrome storage contents, Claude cookies, Claude authentication tokens, or other Claude credentials.

The Cloudflare Worker used for Prompt Enhancer does not intentionally persist prompt text. When rate limiting storage is enabled, the Worker stores an hourly rate-limit counter keyed by IP address for about two hours. Cloudflare may process IP address, request metadata, and related infrastructure logs to provide and secure the Worker service. Anthropic receives the prompt text submitted to Prompt Enhancer to generate the rewritten prompt.

The extension does not sell user data, share user data with advertising networks, or transfer user data to data brokers. Data is shared only as needed to provide the extension features described in this policy, comply with law, respond to your explicit support request, or protect against abuse or security issues.

Human Access

The extension developer does not allow humans to read user data except when:

  • You give explicit consent for a specific support request.
  • Access is necessary for security or abuse investigation.
  • Access is necessary to comply with applicable law.
  • Data has been aggregated and anonymized for internal operations.

Data Retention and Deletion

Settings, todos, saved prompts, and organizer state remain in Chrome extension storage until you delete them, reset the relevant feature data, clear the extension's storage data, or uninstall the extension.

Todo fallback data in claude.ai local storage remains until you clear that site storage or overwrite it through the extension.

Prompt Enhancer rate-limit counters, when enabled on the Worker, expire after about two hours. The extension developer does not intentionally store prompt text submitted to Prompt Enhancer.

Security

The extension transmits data over HTTPS. The extension does not ask for your Claude password, does not read or store Claude cookie values, and does not store Claude authentication tokens.

Limited Use

The extension's use and transfer of user data is limited to providing or improving the extension's single purpose and user-facing features, complying with law, responding to user-approved support requests, and protecting against abuse or security issues.

The extension's use of information received from Chrome extension APIs and Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

The extension does not transfer, use, or sell user data for personalized advertisements, retargeted advertisements, interest-based advertisements, data brokerage, information resale, or credit-worthiness or lending decisions.

Contact

For privacy questions, contact the extension developer through the support contact listed on the Chrome Web Store listing.
