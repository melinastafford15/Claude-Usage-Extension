Privacy Policy for Claude Usage Widget

Last updated: May 7, 2026

Claude Usage Widget is a Chrome extension that displays Claude usage information while you are using claude.ai.

Data Access

The extension reads Claude usage and prepaid credit information from Claude's own authenticated endpoints while you are signed in to claude.ai. This may include usage percentages, reset times, organization identifier data required by Claude's API, prepaid credit balance, and related usage limits.

Data Use

The extension uses this data only to display the floating usage widget on claude.ai.

Data Sharing

The extension does not sell, transmit, store, or share your Claude usage data with the developer or any third party.

Storage

The extension does not use Chrome extension storage, local storage, session storage, cookies, analytics, or tracking services.

Network Requests

The extension only makes same-site requests to claude.ai endpoints needed to display usage information. It does not contact external servers.

Contact

For privacy questions, contact the extension developer through the support contact listed on the Chrome Web Store listing.
